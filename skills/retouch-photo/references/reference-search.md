# Finding useful photographic references

Use this during stage 3, after extracting the target photograph's visual elements.
The goal is a small, inspected set of relevant photographs, not a platform catalog.

## Build queries from the image

Combine the most distinctive evidence: specific landmark/species/object, subject
pose and relationships, environment, framing/perspective, light direction or time
of day, and dominant colors. Use local-language names and English where helpful.
For example, a blue-lit Tsutenkaku framed by yellow shop signs calls for those
elements, not just "beautiful Japan night photography."

Start specific, then relax terms that prevent useful matches. A photograph may
match the subject and framing but use different light; another may match the
light and pose but show a different location. State these differences rather than
calling either an exact match. Weight the elements relevant to the user's request:
composition for a reframing task, skin/light for beauty work, feather detail and
water reflections for a swan photograph. User direction takes precedence over a
reference's look.

## Search images first and screen quality

Search across relevant curated and creator/community sources. Include community
platforms in the search rather than limiting it to awards or famous names; there
is no requirement to visit every site for every photo.

- **Curated/established:** official international award galleries such as World
  Press Photo, Sony World Photography Awards or Wildlife Photographer of the Year;
  photographers' own portfolios, Magnum Photos and National Geographic photography.
- **Creator/community:** Instagram, Unsplash, Flickr, 500px, Behance, Glass or VSCO.
  Pexels and Pixabay can supply additional candidates when relevant.
- **Other collections:** Getty Images, Adobe Stock, Shutterstock or institutional
  collections when they contain a particularly close visual match.

Evaluate visible image quality and fit, not the platform name alone: composition,
tonal hierarchy, color, texture, light and edge quality. Established authorship,
an identified award, credible curation or visible strong engagement can support
selection. High likes/favorites are acceptable evidence of reception, not proof
of technical merit. Do not call a work award-winning or highly liked without
verifying that signal on the source. Exclude visibly poor processing, unsuitable
reference geometry and synthetic images presented as photographic exemplars.

Open and visually inspect candidates. Search text, thumbnails too small to judge,
and an unseen photographer portfolio are insufficient evidence for a style claim.
References are for visual guidance; do not imply permission to copy their content
or assume a platform-wide reuse license. Do not purchase or license a reference
unless the user requests it.

## Access and fallback

Rank inaccessible candidates by how closely they appear to match. For the strongest
matches, including login-gated Instagram or Flickr pages, try the built-in browser
with any existing signed-in session. Use accessible alternatives for weaker
candidates and when browser access fails. Report limitations that affect selection
and claim inspection only for images you actually viewed. Do not download remote
media to bypass display restrictions.

When suitable reference photographs cannot be retrieved after these attempts,
turn to reliable photography textbooks or professional photography/post-production
tutorials. Search using the same extracted elements and the unresolved visual
problem. Identify the source and the applicable lesson; distinguish guidance
from a chosen reference photograph. If some photographs were found but fewer
than requested, show the useful matches and disclose the shortfall rather than
padding the set with unrelated images or counting a tutorial as a photograph.

## Present one reference per plan

For N plans, select N different photographs with the closest useful matches and
distinct aesthetics. Do not reuse one photograph as three supposedly different
reference styles or substitute three technique labels for three visual directions.
Respect any user-selected style by making differences within that direction.

For each reference show the image, its author/title when available, a direct source
link, the matching stage-2 elements, meaningful mismatches, and the aspects to adapt
to the target. Use supported inline media or a browser preview; explain a display
limitation if only a usable link can be provided. Preserve these selections with
the plan so execution can be checked against the same references.

A finished photograph demonstrates an appearance, not the author's editing recipe.
Describe exposure curves, masks or imagegen usage as the proposed implementation
for the user's image unless the source actually documents those methods. Approved
references may be reused during execution or a narrow revision; search again when
the requested visual direction changes or the prior reference no longer fits.
